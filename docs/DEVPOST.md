# Devpost submission text (copy and paste)

## Tagline
AI agents that negotiate your B2B purchases, pay into PayPal escrow, and release funds only when delivery is verified.

## Inspiration
Agentic commerce is coming, but every finance team asks the same question: *what stops the agent from spending money it shouldn't?* We work with industrial customers in mining, logistics and utilities who buy GPS trackers, IoT gateways and safety gear in bulk. Their pain is real: overpaying, paying before goods arrive, and chasing disputes. We wanted agents that do the tedious work of sourcing and haggling while money only moves under rules a CFO would sign.

## What it does
- **Plain English to PO.** An AI planner agent turns "12 AIS-140 trackers, installed within 7 days, under $1,600" into line items, budgets and payment milestones.
- **Agent-to-agent negotiation.** An AI negotiator agent uses strict tool calls to get quotes and send counter-offers to vendor agents, then selects the best compliant offer with a scored rationale.
- **Guardrails the LLM can't bypass.** Deterministic checks cover vendor rating, delivery window, per-order cap, monthly budget, and price at or below list. Deals above a threshold need human sign-off.
- **PayPal as escrow.** Orders v2 with `intent=AUTHORIZE` holds the buyer's funds. Nothing is paid yet.
- **Proof-based release.** The vendor submits delivery evidence (text plus photo). An AI verifier agent with vision decides how much of the milestone is earned, and EscrowPilot **partially captures** exactly that amount. A failed delivery **voids** the authorization. Low-confidence verdicts escalate to a human.
- **Full audit trail.** Every agent, policy, payment and webhook event is shown in AG Grid with search, per-agent filters, confidence bars and CSV export.

## How we built it
- **Google Gemini (`gemini-3.5-flash`)** via the `@google/genai` SDK: JSON-schema structured output for the planner and verifier, function calling for the negotiation loop, and vision for delivery photos. The agent layer is provider-agnostic, and Claude is supported as a drop-in alternative.
- **PayPal Server SDK** (`@paypal/paypal-server-sdk`, generated by **APIMatic** from PayPal's OpenAPI specs) for Orders (create, authorize) and Payments (partial capture, void). The **PayPal JS SDK** handles buyer approval. **Webhooks** are verified with `verify-webhook-signature`.
- **AG Grid Community** powers the escrow ledger and the agent audit trail, with custom status and confidence renderers, quick filter, pagination and export.
- **React + Vite** frontend, **Node/Express** backend with Server-Sent Events for live updates, deployed on **Render** with a one-click blueprint.

## Challenges we ran into
- Mapping "escrow" onto PayPal primitives: authorize-then-partial-capture, with `finalCapture` on the last milestone so the uncaptured remainder automatically returns to the buyer.
- Stopping the model from inventing prices. The final price always comes from the vendor-agent session, never from the LLM's output.
- Making money movement idempotent (`PayPal-Request-Id` per milestone plus a per-deal lock).

## Accomplishments that we're proud of
- An end-to-end agentic purchase where every dollar is traceable to an agent decision, a policy check and a PayPal transaction ID.
- A prompt-injection attempt in delivery evidence escalates to a human instead of releasing funds.
- The project runs fully offline (heuristic agents and mock PayPal), so anyone can try it in two minutes. Add keys and it switches to real Gemini (or Claude) agents and PayPal Sandbox.

## What we learned
Agent autonomy and financial safety aren't in tension if you separate *judgment* (LLM) from *authority* (deterministic code plus the payment rail). PayPal's authorization model is a natural escrow primitive for agentic commerce.

## What's next for EscrowPilot
- PayPal multiparty (Commerce Platform) so vendors are paid directly, with platform fees.
- Reauthorization and vaulting for milestone schedules longer than the authorization honor period.
- Real supplier catalogs (Channel3) behind the same negotiation tools.
- Dispute automation with the PayPal Disputes API, using the audit trail as evidence.
